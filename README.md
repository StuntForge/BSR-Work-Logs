# BSR Member Progress & Upgrade System

Closed, members-only BSR career progression and upgrade administration system.

- `apps/api-web` — Next.js backend API + Committee web portal (deploys to Vercel)
- `apps/mobile` — Expo mobile app for Members / Full Members
- `packages/db` — Prisma schema, client, seed
- `packages/shared` — Shared types/constants used by both apps

See `packages/db/prisma/schema.prisma` for the data model and the product spec for full behaviour.
